安装前请先确认两件事
================================================================

1. Mac 那边已经开了「屏幕共享」

   系统设置 → 通用 → 共享 → 打开「屏幕共享」，
   再到「电脑设置…」里勾选
   「VNC 显示程序可以使用密码控制屏幕」并设一个 8 位以内的密码。

   没开的话，装完之后程序里「检测连通」会是红色，连不上。


2. Windows 这边装了 Tailscale 并登录同一个账号

   https://tailscale.com/download
   装好后本程序会自动列出你 Tailscale 网络里的 macOS 设备。

关于内置的 VNC 客户端
----------------------------------------------------------------
安装时会默认一并安装 TigerVNC 1.16.2 的便携客户端
（vncviewer.exe，约 23 MB）。它遵循 GPL-2.0 许可证，安装包内已附带
许可证原文 bin\TigerVNC\LICENCE.TXT，对应源码见
https://github.com/TigerVNC/tigervnc/tree/v1.16.2 。

如果你不需要它（例如你已经装了 RealVNC / UltraVNC），
可以在"组件"页取消勾选；本程序会自动去查找系统里已有的客户端。

关于 Windows 安全提示
----------------------------------------------------------------
安装包和主程序都没有做代码签名，Windows SmartScreen 可能提示
"已保护你的电脑"。点"更多信息"→"仍要运行"即可。
如果你介意，可以自行用 signtool 签名，或在沙箱/虚拟机里先跑一遍。
