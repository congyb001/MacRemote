Mac 端设置（一次性，约 3 分钟）
==================================================

适用：macOS 26 / 15 / 14 任意 Apple Silicon 或 Intel Mac

原理：Windows 这边用标准 VNC 客户端，直连 Mac 系统自带的
      「屏幕共享」服务（5900 端口），全程走 Tailscale 私有网络。


一、确认 Tailscale 在线
--------------------------------------------------
1) Mac 上打开 Tailscale，确认已登录、状态「Connected」。
2) 记下它的 100.x.x.x 地址（或直接用机器名）。
   本机读到的当前地址是：100.x.x.x（你的Mac主机名）
   —— 换网络或重装后可能变，以 Mac 上显示的为准。


二、打开屏幕共享并设置 VNC 密码
--------------------------------------------------
1) 苹果菜单 → 系统设置 → 通用 → 共享
2) 打开「屏幕共享」开关
3) 点旁边的 ⓘ（或「电脑设置…」按钮），勾选：
      ☑ VNC 显示程序可以使用密码控制屏幕
      （英文：VNC viewers may control screen with password）
4) 在下面那个输入框设一个密码 —— 这就是 Windows 端连接要输入的
   密码，建议 8 位以上，和登录密码区分开。
5) 点「好」。

不勾这一步的话，Windows 端只能看到「只接受 Apple 认证」，
标准 VNC 客户端会被拒（本程序的「检测连通」会显示橙色提示）。


三、允许被连接 / 放行防火墙
--------------------------------------------------
· 首次开启屏幕共享时，macOS 会弹「是否允许…接受传入网络连接」，
  点「允许」。
· 如果开着第三方防火墙（如 Little Snitch），放行 Screen Sharing
  与 5900 端口。


四、别让它睡过去
--------------------------------------------------
Mac 一旦睡眠，远程就连不上（Tailscale 显示离线）。

· Mac mini / 台式机（插电）
  系统设置 → 能源 / 电池 → 「防止电脑自动进入睡眠」设为 开启，
  或在「锁定屏幕」里把「关闭显示器后进入睡眠」设为 永不。
· 笔记本
  插电状态下同上；合盖会睡眠，远程前保持开盖。

想立刻确认，可在 Mac 终端跑：
   caffeinate -dimsu &


五、验证
--------------------------------------------------
Mac 终端执行：
   nc -z 127.0.0.1 5900 && echo OK
（没装 nc 就用：lsof -nP -iTCP:5900 | head）

输出 OK，回到 Windows 打开「Mac远控」，点「检测连通」，
显示绿色「可以连接」就点「开始远程控制」。


常见问题
--------------------------------------------------
· 检测红色：连不上
   依次查：Mac 是否唤醒 → Tailscale 是否 Connected →
   屏幕共享开关是否打开 → 两台机器是否同一个 Tailscale 账号。

· 检测橙色：只接受 Apple 认证
   回到第二步，勾选「VNC 显示程序可以使用密码控制屏幕」。

· 连上了黑屏 / 鼠标点不动
   系统设置 → 隐私与安全性 → 屏幕录制 / 辅助功能，
   把「屏幕共享」重新勾一次，然后关掉屏幕共享再打开。

· 提示密码错误
   那不是登录密码，是第二步里单独设的 VNC 密码；
   在「电脑设置…」里删掉重设即可。

· 想换端口或换机器
   Windows 端程序里直接改地址/端口，不用重装。
