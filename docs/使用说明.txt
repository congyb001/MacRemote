Mac 远控 · 使用说明
==================================================

双击「Mac远控.exe」即可，不用装 Python 或任何运行环境。


界面怎么用
--------------------------------------------------
① Tailscale 设备
   程序启动时会读本机 Tailscale 的设备列表，自动选中你那台
   macOS 主机（你的Mac主机名 / 100.x.x.x）并填进地址框。
   想换机器，下拉选另一台即可；点「刷新」重新读一次。

② 地址与端口
   地址就是 Mac 在 Tailscale 里的 100.x.x.x；端口默认 5900
   （macOS 屏幕共享的 VNC 端口）。也可以直接手填。

③ 三个按钮
   · 检测连通
       真正做一次 VNC 协议握手，不只是 ping。结果分四种：
       绿色  屏幕共享已开，VNC 密码认证可用 → 可以直接连
       橙色  端口通但只接受 Apple 账号认证 → 去 Mac 勾选
             「VNC 显示程序可以使用密码控制屏幕」
       橙色  端口通但没设密码 → 在 Mac 上补一个密码更安全
       红色  连不上 → Mac 睡了 / Tailscale 掉线 / 屏幕共享没开

   · 开始远程控制
       唤起内置的 TigerVNC 客户端连过去。界面「密码」留空时，客户端会弹
       密码框让你手输；界面上填了密码，就直接拿它去认证，不再弹框——
       所以填错密码会立刻报「Authentication or authorization failure」，
       不会给你重输的机会，把密码栏改对再点一次即可。连上后是一个窗口，
       默认全屏打开，把鼠标移到屏幕顶部可以呼出窗口边框。

   · 复制地址
       把 100.x.x.x:5900 复制到剪贴板，方便粘到别的工具里。


画面选项
--------------------------------------------------
· 画质 高速（局域网）：压缩最少、最清晰，Tailscale 直连时选这个
· 画质 均衡：默认值，画面和带宽都兼顾
· 画质 省流量：压缩最狠，走慢速中继或手机热点时用
· 全屏打开：连上直接铺满屏幕（鼠标到顶部边缘可切回窗口）
· 只观看：只看画面，不发送鼠标键盘——演示、监看时用
· 认证方式
     VNC 密码（默认）：用 Mac「屏幕共享 → 电脑设置…」里单独设的那个
       密码，弹框里只要密码，不填就每次自己输。
     Mac 账号：改用 Mac 的用户名 + 登录密码，弹框会多一个用户名栏。
· 密码 + 记住
     填了就自动带过去，不用每次手输。密码只在启动客户端时通过环境变量
     交给子进程，不落地成临时文件；只有勾「记住」时才会混淆后写进
     config.json（不是加密，别存高价值密码）。
     注：标准 VNC 密码认证只认前 8 位，Mac 那边设密码时也建议 8 位以内。


其他按钮
--------------------------------------------------
· 打开 Mac 共享文件夹
   用资源管理器打开 \\100.x.x.x（Mac 文件共享，端口 445）。
   第一次会要 Mac 的共享账号和密码，用于传文件、拷素材。

· Mac 端设置说明
   打开同目录《Mac 端设置.txt》，Mac 那边的一次性设置照做一遍。

· 准备 VNC 客户端
   程序目录 bin\TigerVNC\vncviewer.exe 是内置的，正常不需要点。
   万一被误删，这个按钮会用 winget 从官方源重新装一份。


文件清单
--------------------------------------------------
Mac远控.exe                  主程序
bin\TigerVNC\vncviewer.exe   内置 VNC 客户端（TigerVNC 1.16.2，GPL-2.0）
config.json                  保存的地址、端口、画质、密码（首次退出时生成）
Mac 端设置.txt               Mac 那边的一次性设置
使用说明.txt                 本文件


常见问题
--------------------------------------------------
· 检测红色「无法连接」
   Mac 是否插电、是否被设成睡眠；Tailscale 里那台机器是否「在线」。
   Mac mini 建议：系统设置 → 锁定屏幕 → 关闭显示器休眠，或直接用
   caffeinate 保持唤醒。

· 弹出密码框但密码一直不对
   Mac 上的 VNC 密码和登录密码是两回事，在
   系统设置 → 通用 → 共享 → 屏幕共享 → 电脑设置… 里设置/重置。

· 连上了但画面一片黑 / 点不动
   新版 macOS 会把「屏幕录制」「辅助功能」权限收回，重新在
   系统设置 → 隐私与安全性 里给 Screen Sharing 勾一次即可。

· 点了「开始远程控制」没反应 / 一闪就没
   程序现在会把客户端输出写进同目录的 vnc_last.log 并弹窗提示。
   最常见原因是 bin\TigerVNC\vncviewer.exe 被删或被杀软拦了，
   点右下角「更换 VNC 客户端」重新准备一份即可。

· 安全提醒
   这套连接只走 Tailscale 私有网络，不经第三方服务器；
   但 VNC 协议本身是明文传输，Tailscale 已经提供了链路加密。
